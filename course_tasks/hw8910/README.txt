ДЗ 8+9+10: расследование и исправление процесса выпуска

Полное задание — homework8-9-10.html в корне архива.
Начните с INCIDENTS.txt. В исполняемом прототипе семь независимых дефектов.
Это заготовка для расследования, а не готовое решение и не три функции TODO.

Без весов, без пакетов (Python 3.12):
  python3 lab.py init
  python3 lab.py run --fail-after-prepare
  python3 lab.py run
  python3 service.py --port 8091 --warmup-seconds 10
Сервис привязан к localhost. Прототип HTTP написан на стандартной библиотеке,
чтобы начать опыты без установки окружения. В итоговом проекте требуются Prefect
и FastAPI с внедряемым backend. Условия запуска и HTTP-контракты для тестов
сохраните совместимыми или предоставьте единый адаптер запуска для двух версий.

  python3 -m unittest discover -s tests -v
Часть открытых тестов падает из-за заложенных дефектов. Исправление только
release.py и зелёные 13 тестов — максимум 2/10. Требуются не менее 6 собственных
интеграционных тестов и логи обнаружения дефекта до/после исправления.
Не переписывайте общие tests/ вашего ДЗ 6+7: добавьте новый каталог отдельно.

Сохраните исходную версию отдельным коммитом. В defects.csv внесите семь причин,
связанные исправления и имена тестов. Публичные тесты не покрывают весь проект.
Критерии и интерфейсы ядра — CONTRACTS.txt; план отчёта — REPORT.txt.
Для каждого независимого опыта используйте новый --workspace; init не перезаписывает
существующие каталоги. .lab содержит только маленькие учебные фикстуры.

Затем подключите существующие веса, MLflow-runs и полный gate из ДЗ 6+7.
Новый sweep не нужен. STUB ONLY не является настоящим ответом модели или eval.
Если кандидат отклонён, демонстрируйте настоящий API принятого baseline.
Веса, окружения, кэши и секреты в Git/сдачу не включать. Версии зависимостей закрепить.
Готовые фикстуры не превращать в passed=true для реального выпуска.

ci.example.yml предполагает release.py и tests/ в корне проекта. Включите туда
также свой сервис, flow и новые тесты, а зависимости для быстрого прогона отделите
от весов и тяжёлого генератора. Локальный эквивалент CI полностью засчитывается.
Actions — необязательно; без удалённого run не заявляйте защиту merge.
