# Протокол оценки ДЗ 6+7

Оцениваются исходная база и один кандидат, выбранный по validation loss
завершённого sweep из шести LoRA-конфигураций. Golden не участвует в выборе
кандидата. Условия оценки и критические срезы зафиксированы до нового
запуска оценки по строгому контракту задания.

## Данные и допустимые ответы

Набор `movie-genres-strict-v3` содержит 90 golden-вопросов и 5 отдельных behavioral-кейсов.
Тема — определение жанров фильма по описанию. Источник — публичный
[Pablinho/movies-dataset](https://huggingface.co/datasets/Pablinho/movies-dataset/tree/97da8cd79f0c0ee06c2f45dd30a878967d6d87a4),
ревизия `97da8cd79f0c0ee06c2f45dd30a878967d6d87a4`, лицензия CC0-1.0.

Для всех строк используется один каталог из 932 допустимых строковых меток:
931 канонический набор жанров из закреплённого CSV, включающий все
18 одиночных жанров, и отдельная метка `REFUSE`. Жанры в source-наборах
сортируются и соединяются строкой `, `. Каталог строится из источника,
а не из ответов моделей. Например, `драма, история, семейный` является
одной допустимой строковой меткой, а не тремя выбираемыми частями ответа.

Каталог взят из всего CSV. Это общий labelspace источника; он не является
train-only словарём или словарём, независимым от test. Это ограничение
оценки указано явно. Ни каталог `choices`, ни `expected`, ни source-метаданные
не передаются модели: она получает только `input` и общую system-инструкцию.

Исходные 90 `input`/`expected`, порядок, группы, срезы и 5 behavioral-кейсов
сохранены. Исправление контракта не подбирает вопросы или эталоны по ответам.
В каждой строке `expected` входит в `choices`.

Golden получен из прежнего test, вне полных train/val. По 15 фильмов
выбраны без возвращения из шести страт «до/с 2000 года × 1/2/3+ жанра»:
sample seed `20261025`, отдельный shuffle порядка `20261026`. Получены
45/45 по эпохам, 30/30/30 по числу жанров, 68/22 по длине описания.
В ячейке «до 2000, один жанр» взяты все 15 доступных фильмов. Это
сбалансированный benchmark, а не оценка естественных частот источника.

Источник, жанры и год всех 90 записей сверены с закреплённым CSV и
просмотрены AI-ассистентом. Независимая человеческая переразметка не заявляется.
В manifest сохранены три оговорки о неоднозначной или неполной source-разметке.
Они не исключаются из знаменателя после просмотра результатов.

## Генерация и scorer

Обе модели получают один prompt, chat template, `seed=20261025`,
`do_sample=false`, `enable_thinking=false` и `max_new_tokens=96`.
Точная system-инструкция находится в `evaluation/params.json`.
Baseline — Qwen/Qwen3-0.6B на закреплённой HF-ревизии. Кандидат задаётся
конкретной registry version и training run; подвижный alias не заменяет
точную спецификацию модели в отчёте.

Ответ валиден только как JSON-объект с единственным полем `answer`,
значение которого — строка из `choices`. Верность требует точного
строчного равенства `answer == expected`. Значение не нормализуется:
перестановка жанров, изменение регистра или пробелов внутри метки не
исправляются. JSON с лишними/повторяющимися ключами, неверным типом,
неизвестной меткой или пояснением вместо объекта невалиден.

Accuracy = correct/n, format rate = valid/n. Пустые, неверные и аварийные
ответы остаются в общем n и `per_item`; generation errors учитываются
отдельно. Для каждого среза сохраняются n, correct, valid, errors и доли.
Дубли, несовпадающие id и пустой набор являются ошибками входного контракта.

Полный исходный train-index содержит 4800 вопросов. Проверяются точные
нормализованные plot/group пересечения с train/val. Повторное кодирование
всех 4800 train и 599 val связывает исходные вопросы с настоящими
`input_ids`, `attention_mask`, `labels` тензоров; одних ID недостаточно.
Exact/group проверки не исключают все смысловые перефразы, связи франшиз
и пересечения с предобучением модели.

## Критические срезы, поведение и gate

Критические срезы: `single_genre`, `three_plus_genres`, `before2000`,
`since2000`. Они покрывают простой и многометочный сценарии и обе эпохи.
Дополнительные срезы: `two_genres`, `short_description`, `long_description`;
граница длины — 400 Unicode-символов. Семейства срезов пересекаются,
поэтому их n не суммируются.

Обязательные behavioral-кейсы: формат ответа на исходном вопросе,
настоящий перефраз того же сюжета со связанными source id/group id,
отказ на географический и арифметический запросы вне темы, распознавание
анимации по описанию техники. Они считаются отдельно от golden n=90.
Отказы ожидают `REFUSE`; отказные train-примеры не добавлялись.

Gate допускает кандидата только при совместимых и полных отчётах,
конечных метриках, отсутствии generation errors, общей accuracy и
format rate не ниже baseline, accuracy всех критических срезов не ниже
baseline и прохождении каждого обязательного behavioral-кейса.
Допуск ухудшения равен нулю. Missing/NaN/ошибка/несовместимость дают отказ.
Перед продвижением raw, hashes и метрики перепроверяются.

Сохранены также заранее заданные дополнительные условия: общие micro-F1
и macro-F1 и micro-F1 критических срезов не ниже baseline. Они строже
обязательного минимума задания, дополняют accuracy/format/behavioral
и не ослаблялись после просмотра ответов.

Отрицательная проверка портит отдельную копию ответов; она должна получить
отказ, сохранив исходные raw, веса и aliases. `make promote` разрешён только
после PASS. Отказ по качеству допустим: candidate остаётся доступным,
champion не назначается и baseline автоматически не обновляется.

## Артефакты и доступ

`eval-data.dvc` отслеживает `data/eval`. Переносимый текстовый архив
`docs/datasets/hw67-evaluation.tar.gz` содержит golden, behavioral,
полный train-index и manifest. Веса и тензоры в архив не входят.
SHA256 архива: `4da0960f16151d1792af6797e2dca57eb9764b8a4f8615e34c75d4f0b8cd7e0f`.

```bash
tar -xzf docs/datasets/hw67-evaluation.tar.gz
uv run dvc status eval-data.dvc
```

Повторная подготовка из восстановленного исходного CSV и тензоров:

```bash
make prepare-eval
```

Сырые ответы, per-item результаты, diff и решения gate сохраняются в MLflow
и `metrics/`. После использования golden для разработки его нельзя
называть независимым итоговым аудитом. Сходство слов и модель-судья не
заменяют scorer; judge и платный API для этой сдачи не используются.
