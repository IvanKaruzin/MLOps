# ДЗ 6+7: сохранённый первый эксперимент

Это неизменённые данные, настройки и отчёты первого прохода. Исходный код
доступен в [коммите ddeb036](https://github.com/IvanKaruzin/MLOps/tree/ddeb036d969901b4763385eb09796cf37eaf8848).
Относительные ссылки внутри архивных Markdown относятся к структуре этого
исходного коммита.

- `hw67.yaml`: первые 32 train и 8 val, четыре optimizer steps.
- `hw67-evaluation.tar.gz`: 60 вопросов с четырьмя вариантами ответа.
- `conclusion.md`, `comparison.csv`: исходные выводы и измерения.
- [JSON-отчёты и сырые ответы](../../../metrics/hw67-history/v1/).
- Предыдущая модель: `models:/my-qwen-adapter/2`; она закреплена в
  `evaluation/comparison-models.json` для новой оценки на общем протоколе.

Историческая MCQ accuracy и новая оценка свободных наборов жанров измеряют
разные задачи. Прямое сравнение моделей выполняется заново на одном наборе
и с одним scorer. Архив не используется для подбора новых вопросов или порогов.
