# Сценарий скринкаста ДЗ-3

Это готовый сценарий и чеклист записи. Видеофайл в репозитории не создан:
запись экрана выполняется отдельно перед сдачей.

Перед записью начать с чистой ветки `main` и убедиться, что рабочая версия —
`v2`, а локальный DVC remote доступен.

1. Выполнить `uv run dvc dag` и коротко показать полный граф
   `collect → clean → diversity → split → contamination`.
2. Показать воспроизводимое восстановление v1:
   `git switch --detach data-v1`, `uv run dvc checkout`, затем
   `wc -l data/raw.jsonl data/clean.jsonl data/train.jsonl data/val.jsonl data/test.jsonl`.
   В кадре должны быть объёмы `3000 → 2998 → 2397 + 300 + 301`.
3. Аналогично восстановить v2 командами `git switch --detach data-v2` и
   `uv run dvc checkout`. Показать объёмы
   `6000 → 5998 → 4800 + 599 + 599`. После демонстрации вернуться командой
   `git switch main && uv run dvc checkout`.
4. Выполнить `uv run dvc metrics diff data-v1 data-v2`. Показать реальное
   увеличение числа строк, расширение покрытия лет и языков и сохранение
   нулей контаминации. Краткая интерпретация результата находится в
   `docs/metrics-diff.md`.
5. Выполнить `make contamination` и открыть `metrics/contamination.json`.
   В кадре должны быть четыре нуля для train/test: `id_overlap`,
   `text_overlap`, `group_overlap` и `near_dup_pairs`.
6. Завершить командой `make check` и оставить в кадре финальную строку
   `Все проверки пройдены` вместе со всеми восемью зелёными разделами.

После записи проверить, что терминал не показывает токены, ключи, абсолютные
пути с чувствительными данными или содержимое локального DVC remote. Видео
хранить и передавать отдельно от Git; этот файл остаётся чеклистом показа.
