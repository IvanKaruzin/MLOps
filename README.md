# MLOps: накопительный проект ДЗ-1 — ДЗ-3

Репозиторий объединяет три домашние работы: воспроизводимый инференс Qwen3,
анализ устройства модели и DVC-пайплайн датасета для многометочной
классификации жанров фильма по текстовому описанию. Тема датасета согласована с
преподавателем.

## ДЗ 1 — Окружение, первый инференс Qwen3, бенчмарк машины

## Что нужно сделать

1. Поднять окружение: `uv sync`, закоммитить `uv.lock`.
2. Заполнить `TODO` в коде.
3. **Найти и исправить четыре намеренных дефекта.** Симптомы описаны
   в задании; конкретные строки не указаны — искать нужно самим.
4. Прогнать `make bench`, определить свой профиль железа по таблице курса
   и записать выбранную модель в `params.yaml`.
5. Написать `docs/hardware.md`: результаты замера **и разбор каждого
   найденного дефекта** — в чём был, как проявлялся, как исправлен.
   Простое «починил» не засчитывается.
6. Согласовать с преподавателем тему своего датасета — тема согласована.

## Запуск

```bash
uv sync
make generate     # генерация
make bench        # замеры
make check-hw1    # самопроверка ДЗ-1
```

## Подсказка по железу

Модель выбирается **только** через `params.yaml`. Если ваша машина
не тянет базовую — возьмите `HuggingFaceTB/SmolLM2-135M-Instruct`.
Оценивается пайплайн, а не качество модели.

## ДЗ 2 — Анатомия модели

Каркас ДЗ-2 перенесён в общий проект. Новые модули —
`src/inspect_model.py` и `src/report.py`, шаблон сводной таблицы —
`docs/anatomy-worksheet.xlsx`. Конфигурация и окружение общие с ДЗ-1.

```bash
uv sync
make inspect      # разбор модели, отчёт и график в docs/
make check-hw2    # семь проверок ДЗ-2
make check-hw1    # пять проверок ДЗ-1
make check-all    # последовательно ДЗ-1, ДЗ-2 и ДЗ-3
```

Четыре учебных дефекта исправлены. Параметры считаются по уникальным
тензорам, hooks снимаются в finally, каждый замер памяти запускается в
отдельном процессе. Для MPS используется максимум driver_allocated_memory,
а RSS сохраняется отдельно. Подробности и результаты — в [отчёте](docs/anatomy.md).

Быстрые проверки:

```bash
uv run python -m src.inspect_model --params-only
uv run python -m src.inspect_model --hooks-only
uv run python -m unittest discover -s tests -p 'test_*.py'
```

[Сценарий скринкаста](docs/screencast.md) содержит порядок демонстрации.

Результаты ДЗ-2: `docs/anatomy.md` с условиями замера и разбором четырёх
дефектов, `docs/activations.png`, заполненный `docs/anatomy-worksheet.xlsx`,
`uv.lock` и сценарий демонстрации семи зелёных проверок `make check-hw2`.
Полная формулировка находится в `course_tasks/hw2/2-zadanie-dz2.html`.

## ДЗ 3 — Датасет жанров фильмов и DVC

Датасет построен из зафиксированной ревизии
[`Pablinho/movies-dataset`](https://huggingface.co/datasets/Pablinho/movies-dataset)
с лицензией CC0-1.0. Название фильма исключено из пользовательского prompt:
модель классифицирует только описание. Пайплайн состоит из пяти стадий:

```text
collect → clean → diversity → split → contamination
```

Доступны две воспроизводимые версии данных:

| Версия | Git-тег | Raw | Clean | Train / val / test |
|---|---|---:|---:|---:|
| v1 | `data-v1` | 3 000 | 2 998 | 2 397 / 300 / 301 |
| v2 | `data-v2` | 6 000 | 5 998 | 4 800 / 599 / 599 |

Групповой split не разделяет фильмы одного года между выборками. Для активной
v2 пересечения train/test по ID, нормализованному тексту, году и near-duplicate
равны нулю.

### Воспроизведение и проверки

```bash
uv sync
uv run dvc pull        # восстановить исходник и текущие артефакты
make repro             # воспроизвести весь DVC DAG
make check             # восемь проверок ДЗ-3
make check-hw1         # регрессия ДЗ-1
make check-hw2         # регрессия ДЗ-2
make check-all         # полный набор проверок
```

Переключение версий выполняется только штатными целями:

```bash
make v1
make v2
uv run dvc metrics diff data-v1 data-v2
```

Данные `data/`, исходный snapshot и DVC remote не хранятся в Git. В Git
остаются код, конфигурация, `dvc.lock`, DVC pointer и небольшие JSON-метрики.

Документация ДЗ-3:

  и ограничения;

- [сценарий скринкаста](docs/screencast.md) — порядок демонстрации результата.
